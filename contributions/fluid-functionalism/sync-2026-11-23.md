# Fluid sync to upstream `1f716642` (Nov 21, 2026)

Every installed primitive was compared with the exact upstream registry
revision it was copied from (closest match across that item's full history),
then three-way merged against `mickadesign/fluid-functionalism@1f716642`.
Local adaptations were replayed on top; nothing was overwritten blindly.

## Outcome by file

- **Unchanged upstream, local adaptations only:** combobox, input, switch,
  elevated, springs, type-scale, omit, shape-context, size-context,
  surface-context.
- **Taken from upstream (no local changes):** date-picker, dropdown-search,
  dropdown-sub, fluid-hover-highlight, mobile-drawer, thinking-indicator,
  use-fluid-hover, use-merge-split, icon-context, popup. New: `lib/key-cap`.
- **Merged, local adaptations kept:** accordion, badge, banner, button,
  calendar, command-menu, date-picker-core, dialog, dropdown, input-copy,
  menu-item, select, sidebar, sidebar-core, sidebar-menu, slider, table,
  thinking-steps, tooltip, surface-classes, utils, data-table.
- **Upstream rebased, IA changes replayed:** radio-group (horizontal
  orientation, reduced motion, touch), checkbox-group (disabled rows,
  muted-foreground unchecked border, reduced motion, touch), tabs-subtle
  (upstream renamed `TabsSubtle` to `Tabs`; IA keeps the `TabsSubtle` names
  and its reduced-motion and touch-target changes).
- **Kept local, targeted fixes ported:** scroll-area (stable memoized
  viewport, inset focus outline, thumb nudge), card (inset focus ring,
  sideways-only title clip), collapsible (`CollapsePanel` snap hand-off).
- **Kept local, deliberately not merged:** file-thumbnail (optional PDF
  renderer and abort lifecycle), color-picker (April base, upstream rewrote
  about 2,000 lines; two callers), tabs (IA's segmented Radix tabs; upstream
  dropped them).
- **Not Fluid copies (same names, different origin):** breadcrumb,
  context-menu, field, message-scroller, textarea, font-weight. Their
  registry diffs are not merges.

## DataTable

Upstream grew from about 3,600 to 8,400 lines: a column menu on header
click (sort, filter, move, freeze), row virtualization, row drag,
`DataTableFilters` and `DataTableFilterChips`, an undo hook, and a search that
rests as an icon button.

IA keeps its composition API on top:

- `DataTableColumnHeader` stays the scoped provider. `DataTableColumnHeaderLabel`
  is now upstream's header body (menu included), reading the column from an
  internal context.
- `DataTableSearch` is upstream's collapsible search, providing
  `useDataTableSearch`. Composed children (audit suggestions) keep it open.
- `groupLabel`, `rowDetail` and the row-detail animation sit on upstream's
  new row renderer.

Behavior changes callers will see: a plain header click opens the column menu
(Shift-click still sorts), searches without composed children collapse to an
icon, and columns size to their content with the last one taking the rest.
The admin table test now sorts with Shift-click and stubs `Range` geometry
for jsdom.

## Upstream bugs found

- DataTable renders its stylesheet (`PIN_CSS`) only when a column is frozen,
  but that sheet also hides the hovered row's edge fade bands. A table with no
  frozen column shows dark fades at both ends of every hovered row. IA renders
  the sheet always.
- Upstream `command-menu` now imports the renamed `Tabs`; IA points it at
  `TabsSubtle`.
